# data-coverage Specification

## Purpose

提供逐環節及逐題材的研究與自動來源覆蓋資訊，保留近三十與九十日內容直接相關事件的數量與實際更新狀態，讓研究者辨識既有證據、資料缺口及來源限制，避免把公司提及或推導當成新聞覆蓋。

## Requirements

### Requirement: 覆蓋矩陣與缺口

系統 MUST 為所有環節及題材顯示研究內容、已設定與成功來源、最近更新、近 30／90 日直接事件數與真實分類樣本。背景統計、公司提及、未知發布日與 inference MUST 分開計數；未取得資料 MUST 明示缺口，並提供可保存的近 90 日矩陣。

#### Scenario: 某環節沒有直接事件
- **WHEN** 來源只有公司財報、背景統計或尚未成功
- **THEN** 該環節的直接事件數為零，保留研究與來源狀態並指出缺口

### Requirement: 回補與持續更新

系統 MUST 首次嘗試回補來源可提供的近 90 日資料，其後每小時更新；MUST 顯示實際取得範圍、分頁限制及部分失敗，不得宣稱來源不可取得的歷史已完整回補。

#### Scenario: 來源僅提供有限 RSS 歷史
- **WHEN** 回補到 feed 或分頁的歷史上限
- **THEN** 報告實際範圍與限制，後續重跑不重複建立事件

### Requirement: 近期零事件與來源狀態分開

覆蓋資訊 MUST 同時明示近 30 日與近 90 日直接事件缺口，並與未設定、未成功、持續失敗的來源分開。近 30 日零事件 MUST 不被較舊事件或最近 HTTP 成功掩蓋，也不得被宣稱為產業沒有變化；公司提及或結構推導不得補成直接事件。

#### Scenario: ODM 有歷史但沒有近期直接分類
- **WHEN** ODM 近 90 日有事件而近 30 日直接事件為零
- **THEN** 顯示近期直接資訊缺口，保留實際來源狀態與歷史事件

### Requirement: 判讀與指標覆蓋獨立可見

題材的覆蓋資訊 MUST 分開顯示研究全文、結構化判讀與查核日、事件分類、指標設定／取得及其缺口。代理指標有值 MUST 不代表題材專屬資料已取得；來源成功、離線樣本或版本數量 MUST 不代表判讀已更新或內容已核實。既有覆蓋計數與可保存報告 MUST 保持可用。

#### Scenario: 新聞很多但專屬指標未取得
- **WHEN** 某題材有直接新聞與公司整體營收，但尚無產品收入資料
- **THEN** 分別呈現已有內容與專屬數據缺口，不以新聞量或代理值將缺口標為完成

### Requirement: 技術研究覆蓋與文件待核對獨立呈現

覆蓋 API 與可保存維護報告 MUST 對所有目前環節及題材列出技術研究面向是否整理、可回溯論述及文件、已核對版本／日期、待核對更新與具體缺口。技術文件數、來源設定數、新聞量或代理指標有值 MUST NOT 被當成研究完整或論述已核實；沒有技術證據的面向 MUST 可明示尚待補強。

#### Scenario: 有新聞但缺少替代限制證據
- **WHEN** 某環節已有近期直接事件而替代條件尚無可核對文件
- **THEN** 事件數照實呈現，技術研究面向保留缺口，不因有新聞而標為完成

#### Scenario: 原研究引用舊版文件
- **WHEN** 文件監測發現尚未核對的新版本
- **THEN** 維護報告同時保存既有已核對基準與待核對候選；一般覆蓋頁不展示維護佇列，不將研究查核日期改成取得日

### Requirement: 技術來源故障不遮蔽既有研究與報告

覆蓋 API 與可保存維護報告 MUST 在技術來源失效、版本未知或尚無全文時仍提供既有研究、必要摘錄、來源限制及缺口。既有 30／90 日直接事件、背景、未知日期、公司提及、指標與判讀計數 MUST 維持原定義；技術文件觀測 MUST 分開呈現。

#### Scenario: 文件 403 但研究已核對
- **WHEN** 已引用的文件目前回應 403
- **THEN** 報告保留查核日、版本與研究，另列目前取得失敗及最後成功
- **AND** 不把研究列為不存在，不把文件觀測補算成直接新聞

### Requirement: 全圖閱讀與缺口驗收可逐列追溯

交付 MUST 提供涵蓋目前 17 個環節及 7 個題材的可保存驗收矩陣，逐列記錄閱讀入口、技術面向、證據與適用範圍、來源限制、未解缺口及實際查核結果。矩陣 MUST 來自當次資料與走查，離線 fixtures 與真實取得紀錄 MUST 可區分；來源不足可保留明確缺口，不得以示範值補齊。

#### Scenario: 完成全圖走查
- **WHEN** 維護者依矩陣查閱全部環節與題材
- **THEN** 每列可回到對應研究與證據，並分辨已核對內容、條件推論及仍待核實事項
- **AND** 初版與來源失效情境均可閱讀，不將測試樣本宣稱為真實覆蓋
