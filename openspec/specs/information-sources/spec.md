# information-sources Specification

## Purpose

維護一份免費公開資訊來源的註冊表，宣告每個來源的所屬市場、資料類型與可達性，讓後續的消息蒐集能有一份可信、可稽核且不含付費門檻的來源清單。

## Requirements

### Requirement: 來源以單一結構化註冊表宣告

所有資訊來源 MUST 宣告於單一結構化註冊表中，依市場與資料類型分組。每個條目 MUST 包含穩定唯一 ID、名稱、位址與資料類型；自動來源 MUST 有擷取設定與範圍。註冊資訊、人工網頁可讀性及實際擷取健康 MUST 分開，消費端可直接列舉而無需解析散文。

#### Scenario: 列舉特定市場的特定資料類型

- **WHEN** 消費端要求台股的公開申報類來源
- **THEN** 取得該分組下的所有來源條目，每筆含穩定 ID、名稱與位址

#### Scenario: 來源條目缺少必填欄位

- **WHEN** 某來源缺少 ID、名稱、位址、類型或自動設定格式錯誤
- **THEN** 結構驗證失敗並指出該條目

### Requirement: 註冊表僅收免費公開來源

註冊表 MUST 僅包含無需付費、無需 API key 即可取用的來源。需要付費訂閱或私有憑證的來源 MUST NOT 出現於註冊表中。

#### Scenario: 嘗試加入付費來源

- **WHEN** 一個需要付費訂閱或 API key 的來源被加入註冊表
- **THEN** 該條目不被接受
- **AND** 驗證指出註冊表僅限免費公開來源

#### Scenario: 公開申報來源

- **WHEN** 加入公開資訊觀測站或 SEC EDGAR 等公開申報來源
- **THEN** 該條目被接受

### Requirement: 每個來源標記可達性與查核時間

每個來源條目 MUST 帶有可達性狀態與最後查核日期。建立或更新條目時若來源無法連通，MUST 標記為未驗證並記錄查核日期，MUST NOT 以未標記的方式留下失效位址。

#### Scenario: 來源無法連通

- **WHEN** 新增來源時其位址無法連通
- **THEN** 該條目標記為未驗證並記錄查核日期
- **AND** 條目仍保留於註冊表中供日後重試

#### Scenario: 來源查核通過

- **WHEN** 來源位址確認可達
- **THEN** 該條目標記為已驗證並記錄查核日期

#### Scenario: 缺少可達性標記

- **WHEN** 某來源條目未帶可達性狀態或查核日期
- **THEN** 結構驗證失敗

### Requirement: 來源可關聯到地圖環節且引用需可解析

來源條目 MUST 能宣告其主要涵蓋的產業環節。若條目宣告了涵蓋環節，其每個環節識別碼 MUST 解析到地圖中既存的環節。

#### Scenario: 來源宣告涵蓋環節

- **WHEN** 某產業媒體來源宣告涵蓋先進封裝與晶圓代工環節
- **THEN** 消費端可由該環節反查對應的來源清單

#### Scenario: 來源引用不存在的環節

- **WHEN** 某來源宣告的涵蓋環節不存在於地圖中
- **THEN** 結構驗證失敗並指出該來源與無法解析的識別碼

### Requirement: 來源覆蓋全部環節與題材

每個環節及題材 MUST 至少有一個免費自動來源設定，涵蓋科技新報半導體／零組件／伺服器／能源、Semiconductor Engineering RSS、TPCA 公開消息及經濟部／Census M3／EIA 電力月報；設定範圍 MUST 不代表實際已取得直接事件。

#### Scenario: 來源存在但擷取失敗
- **WHEN** 自動來源設定可解析但實際 HTTP 失敗
- **THEN** 保留來源設定並顯示 failed，不以 reachability 的 verified 取代 runtime 狀態

### Requirement: 技術文件沿用單一來源註冊表

技術文件的公開入口 MUST 納入既有單一來源註冊表，支援跨市場技術來源分類及可解析的環節／題材引用；文件紀錄 MUST 引用該來源 ID，不另立重複來源清單。新增分類 MUST 不使既有申報、法說、產業媒體與官方統計來源無法驗證或執行。

#### Scenario: 跨市場規格組織入口
- **WHEN** 新增同時涵蓋互連及先進封裝的公開技術來源
- **THEN** 可從兩個環節查得相同來源身分及相關文件，不需假設其屬台股或美股
- **AND** 既有自動事件與指標來源設定仍正常解析

### Requirement: 技術來源逐入口確認可讀範圍

系統 MUST 優先評估 OCP、OIF、UCIe、IEEE IRDS 與 JEDEC 的官方公開資料，逐入口記錄實際可讀範圍、文件性質、查核日及取得限制。免費摘要、需申請全文、登入或付費內容 MUST 分開；註冊為可讀者只能是無需付費、API key 或私有登入即可取用的範圍。不得以組織知名度或 HTTP 200 代替內容核對。

#### Scenario: 公開索引但全文須申請
- **WHEN** 官方索引或介紹可直接閱讀，規格全文仍須申請
- **THEN** 可登錄公開介紹及其限制，全文不列為已讀、已驗證或自動可取用
- **AND** 研究者可辨識缺少的是全文而非來源組織完全沒有公開資訊

#### Scenario: HTTP 200 回傳登入或驗證頁
- **WHEN** 來源回應成功狀態碼但沒有目標公開內容
- **THEN** 顯示可讀性未確認及實際原因，不製造文件版本或研究證據

### Requirement: 技術監測範圍與擷取健康獨立

技術來源 MUST 明示採人工核對或自動監測、可取得的文件範圍、頻率與數量限制。來源可讀性、最後嘗試／成功及錯誤 MUST 分開，MUST NOT 把來源存在、註冊涵蓋或索引成功當成所有文件已讀或近 90 日直接新聞覆蓋。

#### Scenario: 只有人工核對的規格
- **WHEN** 某公開文件沒有可靠的自動版本辨識方式
- **THEN** 顯示人工核對方式及最後查核基準，不顯示虛構的每小時文件更新成功
- **AND** 既有自動事件來源的覆蓋狀態不被人工技術來源取代
