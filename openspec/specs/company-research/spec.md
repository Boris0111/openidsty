# company-research Specification

## Purpose

提供以公司代號識別且可互相跳轉的公司研究頁，彙整產業角色、可追溯企業關係、官方基本財報與相關事件，協助非專業投資人了解公司在供應鏈中的定位與資料限制。

## Requirements

### Requirement: 固定模板公司頁與唯一識別

系統 MUST 合併同一公司的跨環節角色並提供唯一新版公司研究頁，以穩定公司身分識別、保留 canonical ticker 入口相容。新版 MUST 顯示商業模式、產品線、客戶／供應商、競爭者、業務曝險、風險與來源，不提供公司財務數值或財報頁；既有公司網址 MUST 轉到對應的唯一新版公司研究，legacy API 保持可用但不再回傳財務欄位。未知公司 MUST 回傳不存在，資料不足 MUST 在相關內容旁精簡說明，不填零或生成假內容。

#### Scenario: 跨環節公司
- **WHEN** 使用者從運算或網通開啟博通
- **THEN** 進入同一公司頁，並可看到兩個環節角色與回到環節研究的連結

#### Scenario: 舊 ticker 入口
- **WHEN** 開啟既有公司網址或呼叫既有公司 API
- **THEN** 舊公司網址轉到對應的唯一新版公司研究，既有公司 API 仍可使用，回應不含財務欄位

### Requirement: 深研內容與業務曝險界線

首批五領域的 26 家公司 MUST 完成商業模式、產品用途、差異、已公開客戶／供應商、競爭、風險與來源的研究檢閱。未公開、未取得、未研究及不適用 MUST 可區分；有根據的缺口可保留，但不得以空模板視為完成。公司總營收不得當成特定 AI 產品營收，未公開占比不得自行估計。

#### Scenario: 公司沒有揭露液冷收入
- **WHEN** 公司提供液冷產品，但只揭露合併總營收
- **THEN** 產品能力不以公司總營收代表產品收入，液冷收入占比明示未取得或未公開及其查核依據

### Requirement: 公司比較只並列研究內容

公司比較 MUST 支援 2 至 4 家不同公司，並列各公司的業務模式、供應角色、產品、風險、研究判斷與缺口；選擇少於 2 家、多於 4 家或重複公司 MUST 拒絕並說明原因。比較 MUST 固定於同一個研究版本，不呈現任何公司財務數值、排名或財務口徑選擇。某公司缺少某項研究內容時 MUST 明示缺口，不得以其他公司的內容補齊或推估。

#### Scenario: 比較兩家公司的供應角色
- **WHEN** 讀者選擇台積電與日月光比較
- **THEN** 並列兩家公司的業務模式、供應角色、產品與風險，頁面不出現營收、EPS 等財務數值或財務口徑選單

#### Scenario: 選擇超過上限
- **WHEN** 讀者嘗試加入第 5 家公司
- **THEN** 系統拒絕並說明比較只支援 2 至 4 家不同公司

#### Scenario: 某公司缺少風險段落
- **WHEN** 被比較的公司研究尚未撰寫風險
- **THEN** 該欄明示尚未研究，不留白也不以其他公司內容代替

### Requirement: 公司深化以具體產品交付範圍為依據

納入本次深化的公司 MUST 說明所供應的產品／服務、價值鏈位置、可核對的技術或交付差異、競爭比較的條件、業務曝險與風險。公司能力 MUST 有對應產品或適用產品家族的來源，並與具名客戶採用、量產及收入證據分開；既有 deep 標記不得代替新增產品的查核。

#### Scenario: 已深研公司進入新的產品角色
- **WHEN** 一家既有 deep 公司被納入新的配電設備或光通訊產品研究
- **THEN** 新能力關聯引用直接支持該交付內容的主張與來源，不沿用無關產品的證據

#### Scenario: 只找到廠商能力介紹
- **WHEN** 官方產品頁支持供應能力，但沒有公開客戶或出貨資料
- **THEN** 公司可連到相應產品，研究明示客戶與量產證據的缺口，不建立具名供應關係

### Requirement: 供應角色的代表公司選擇可核對

每個納入擴充的供應角色 MUST 交代代表公司的選擇依據及市場覆蓋限制，先核對既有公司身分與法律主體，再建立或沿用公司頁。公司比較 MUST 以相同交付角色和明示條件進行；一家公司的營收分類、母子公司關係或舊產品競爭名單不得自動代表新產品市場。

#### Scenario: 新供應者實際是既有公司的別名
- **WHEN** 新來源使用不同名稱描述既有法律主體
- **THEN** 沿用其穩定公司身分與適用別名，不重複建立公司或把不同法律主體按近似名稱合併

#### Scenario: 某市場沒有找到符合角色的公司
- **WHEN** 已查核的免費公開來源仍不足以確認某市場的代表供應者
- **THEN** 記錄搜尋範圍與研究限制，不為達到公司數量或市場配額加入無依據公司
