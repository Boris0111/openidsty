# theme-indicators Specification

## Purpose

為產業題材提供有來源、期間與口徑的實際指標及商業化核對資訊，讓使用者分辨題材專屬數據、代理訊號與背景資料，並保留官方修訂、未取得資料及無法比較的限制。

## Requirements

### Requirement: 每個題材的指標定義與缺口

每個現有題材 MUST 至少有一個具名稱、衡量範圍、單位、期間口徑、來源與更新頻率的指標設定。指標 MUST 區分 direct、proxy 與 background，並說明推導限制。無數值、未設定、來源失敗或期別過舊 MUST 可辨識，不得填零或用新聞筆數代替實際指標。

#### Scenario: 以公司月營收觀察液冷題材
- **WHEN** 題材顯示散熱公司的整體月營收
- **THEN** 標為 proxy，明示它不等於液冷產品收入及市場滲透率

### Requirement: 觀測值有完整來源與期間

每筆觀測 MUST 保存可核對數值、來源文件、必要原始摘錄、資料起迄、原始期別、單位／幣別、口徑、發布語意及取得時間。未知發布日 MUST 留空，財報年度 MUST 不被直接改為曆年季度；數值缺少明確標籤或期間時 MUST 不建立有效觀測。

#### Scenario: 來源只有統計報告索引
- **WHEN** 官方頁面只有報告月份與連結而沒有可解析數值
- **THEN** 顯示資料缺口，保留索引來源，不生成觀測值

### Requirement: 趨勢僅比較相同口徑

趨勢與衍生增減 MUST 僅使用同指標、同單位／幣別及可比較期間口徑的已取得觀測；月、單季、累計與年度 MUST 分開呈現。缺少比較期或分母為零 MUST 不計算增幅，實際零值 MUST 與未知值分開；不得以插值或估算補成已發生資料。

#### Scenario: 累計與單季並存
- **WHEN** 資料包含上半年累計與第二季單季收入
- **THEN** 不將兩筆連成同口徑趨勢或直接計算季增率

### Requirement: 重跑與官方修訂可追溯

相同文件及期別的相同數值重跑 MUST 不重複建立觀測；官方修訂數值、單位或口徑 MUST 保存前版本及修訂來源，明確標示最新有效觀測。擷取失敗 MUST 保留既有數值與其期間，不以最近嘗試時間冒充數值已更新。

#### Scenario: 同期數值修訂
- **WHEN** 官方修正同一期別的產品收入
- **THEN** 最新數值有修訂標記，舊值與來源仍可查閱，重跑不增加相同修訂

### Requirement: 商業化里程碑需證據確認

系統 MUST 分開呈現預期查核時間與有來源的里程碑核對，區分 unconfirmed、confirmed 與 contradicted。已確認或被反證的核對 MUST 引用具體證據與適用範圍；日期經過、合作名單、指標上升或新聞提及 MUST NOT 自動完成里程碑或升級題材狀態。

#### Scenario: 預期出貨時間已經過去
- **WHEN** 某預期里程碑日期已過，但沒有可核對交付證據
- **THEN** 維持 unconfirmed，顯示待確認，不能展示為已完成出貨

### Requirement: 首輪有真實指標樣本

交付 MUST 包含 AAON 所揭露的液冷產品收入與台積電所揭露的 2nm 晶圓營收占比之真實來源解析樣本，以及現有可取得的官方財務代理觀測。所有題材 MUST 顯示各自取得狀態；live 無法取得時 MUST 交付來源限制記錄，離線 fixtures 不得發布到正式 runtime。

#### Scenario: 題材專屬數字與公司整體數字並存
- **WHEN** 查看液冷產品收入、公司整體營收與製程營收占比
- **THEN** 每個數值的衡量對象、單位與證據界線可辨識，不被合併成市場規模或股價判斷
