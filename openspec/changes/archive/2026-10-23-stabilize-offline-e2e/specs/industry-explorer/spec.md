# Spec Delta

## ADDED Requirements

### Requirement: 閱讀頁在手機寬度與縮放時不水平溢出

產業地圖與研究閱讀頁在 390px 以上的視窗寬度 MUST 不產生水平溢出，頁面寬度不得超過視窗寬度。視窗由寬變窄（例如手機轉向、桌機縮放視窗）的過程中，關係圖等依前一個尺寸繪製的元件 MUST 不撐寬頁面，在重新繪製前也不得出現水平捲動。關係圖既有的縮放比例、平移與互動 MUST 不因此改變。

#### Scenario: 由桌機寬度縮到手機寬度
- **WHEN** 讀者在 1440px 寬開啟有關係圖的研究頁，接著把視窗縮到 390px
- **THEN** 縮窄的當下與之後，頁面都不出現水平捲動；關係圖在新寬度內重新繪製

#### Scenario: 縮放後保留關係圖狀態
- **WHEN** 讀者先放大關係圖，再把視窗放寬又縮回手機寬度
- **THEN** 關係圖保留原縮放比例，頁面沒有水平溢出

#### Scenario: 直接以手機寬度開啟
- **WHEN** 讀者以 390px 寬直接開啟產業地圖或研究頁
- **THEN** 頁面寬度不超過視窗寬度
