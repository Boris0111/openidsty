# 清晰判讀依據與題材持續追蹤

## Why

使用者需要清晰的產業趨勢與題材進展判斷依據；現有完整散文、分類新聞與結構遍歷尚未將支持證據、反證、成立條件及缺口整理為可快速檢閱的判讀。2026-10-14 檢視另確認資料覆蓋頁遭 Git 忽略、官方來源仍有未設定或失敗狀態，應先補交付與資料可信度再新增判讀入口。

## What Changes

- **P0：可靠性先行。** 修正 `coverage/` 誤忽略功能目錄的規則並納入既有頁面；建立以乾淨 checkout 為基準的離線建置與導覽檢查，避免本機容器掩蓋漏檔。
- **P0：來源與近期缺口。** 提供 SEC 設定／官方 IR 失敗的可操作排查、重試與驗證流程；保留無法取得的實際缺口。覆蓋頁明示近 30 日零直接事件，並以真實樣本檢查 ODM 的分類或來源缺口。
- **P1：證據加有條件判讀。** 為現有七個題材提供判讀摘要、查核基準、支持與反向證據、成立條件、資料缺口、下一個確認點及少量有依據的傳導假設；每個論點保留來源、期間與證據界線。
- **P1：判讀與自動資訊分開。** Markdown 為研究與判讀的唯一來源；自動更新事件作為候選新證據，不因新聞量、關鍵字或擷取時間自動升級狀態。公開介面保留產業圖、題材全文、既有唯讀 API 與輕量公司頁。
- **P1：閱讀順序。** 題材頁先呈現判讀卡及支持／反證，再呈現全文、預期查核點與近期事件；完整結構候選路徑可展開，與具成立條件的傳導假設分開。
- **P2：實際指標與商業化進度。** 所有題材提供指標定義、資料口徑及缺口；首輪接入既有官方公司財務代理指標、AAON 液冷產品收入與台積電 2nm 晶圓營收占比。動態數值自動更新並保存修訂；代理指標不當成題材收入。里程碑需具體證據才能標示已確認或被反證。
- **P3：判讀版本與關注題材。** 保存每次研究判讀的實質修改及原因，顯示版本差異；提供此裝置的題材關注清單，區分判讀更新、指標修訂與候選新資訊。

### 本次範圍與優先順序

使用者已選擇完整四階段，本 change 的 tasks 按 P0 → P1 → P2 → P3 排列，後一階段在前一階段的必要檢查通過後開始。主要對象為廣泛散戶，判斷焦點為產業趨勢及題材進展，採證據加有條件判讀；沒有分數、買賣訊號或教學流程。

| 優先序 | 工作 | 階段驗收 |
|---|---|---|
| P0 | 乾淨 checkout、來源操作與近期缺口 | 覆蓋頁已納入 Git；離線 CI 與來源失效／缺資料情境通過 |
| P1 | 七題材判讀、支持／反證與傳導條件 | 每個判讀能追溯來源、查核日、成立條件、缺口與下一確認點 |
| P2 | 實際指標、口徑、修訂與商業化進度 | 兩項題材專屬指標及既有可取得代理數據有真實樣本；未取得項目逐項列缺口 |
| P3 | 判讀差異與個人關注 | 重跑不生成假更新；跨版本可比較；此裝置關注與已讀狀態可保存 |

AI 判讀、帳號、跨裝置同步、Email／推播、行情／估值與公司比較維持後置。來源限制與維護者未提供的 SEC 設定必須保留為實際缺口；不將新聞數量、公司總營收或題材候選清單當成商業化證明。

## Capabilities

### New Capabilities

- `theme-assessments`: 可追溯的題材判讀、支持／反證、成立條件、缺口、傳導假設與判讀版本差異。
- `theme-indicators`: 題材指標、可核對的動態觀測、原始期間與口徑、修訂及商業化進度。
- `theme-watchlist`: 此裝置的關注題材、判讀／指標更新摘要與已讀狀態。

### Modified Capabilities

- `platform-runtime`: 從版本控制的乾淨 checkout 重現所有公開入口，並檢查來源設定與失敗恢復結果。
- `industry-map`: 題材可攜帶結構化判讀及引用，維持 Markdown 唯一來源與原查核基準。
- `industry-explorer`: 題材閱讀優先呈現判讀與證據，結構遍歷與有條件傳導假設分開閱讀。
- `data-coverage`: 近 30 日直接事件缺口、判讀基準、指標取得與來源設定／失敗狀態分別可見。
- `official-information-ingestion`: 指標來源接入每小時更新，保留重跑一致、修訂及部分失敗隔離。

## Impact

影響 Git 忽略設定、CI／驗證腳本、來源排查文件、題材 Schema 與驗證器、七份題材研究、來源及指標定義、FastAPI 的投影／唯讀介面及 Next.js 題材／事件／覆蓋／關注頁。沿用現有堆疊與免費公開來源；P1 判讀利用既有 Theme JSON，P2／P3 additive migration 新增指標觀測與判讀版本，不刪除歷史資料。

新增題材判讀、指標、版本／差異及公開更新摘要查詢，既有題材回應增加摘要欄位；關注與已讀狀態存在瀏覽器，公開 API 維持唯讀。離線 CI 使用測試程序或 browser request interception，正式 runtime 不讀取測試 fixtures；外部 HTTP 403 不以虛假成功或杜撰證據補齊。
