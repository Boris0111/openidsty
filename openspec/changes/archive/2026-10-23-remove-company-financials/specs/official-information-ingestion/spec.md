# Spec Delta

## MODIFIED Requirements

### Requirement: 官方資訊可追溯

系統 MUST 介接免費官方資料、產業媒體及背景統計；每個事件 MUST 保留來源識別、URL、原始資料與取得時間。發布日、出表日、活動日 MUST 分開，未知發布日 MUST 保留空值，日期精度為日時 MUST 不顯示午夜。沒有單一公司事件 MUST 允許空 ticker；只有外殼或無內容 MUST 視為失敗。

#### Scenario: 官方資料與外殼頁面
- **WHEN** 來源回傳可解析公告
- **THEN** 建立可點回來源的事件
- **AND** 若只回 JavaScript 外殼，來源狀態顯示未成功，既有資料仍保留

#### Scenario: 出表日與活動日期
- **WHEN** 台灣月營收只有出表日期或 IR 只有活動日期
- **THEN** 不將該日期宣稱為真正發布日，取得時間另行保留

### Requirement: 重跑一致與來源隔離

同一來源文件重跑 MUST 不重複建立事件與營收觀測；同一提供者的跨 feed 文章 MUST 以 canonical URL 去重，統計報告 MUST 依資料集與期別識別。某來源失敗 MUST 不阻止其他來源成功，並保留最後嘗試、最後成功、錯誤原因及新增筆數。不同提供者未確認同一事件時不得僅憑標題合併。

#### Scenario: 部分來源失敗後重試
- **WHEN** 一來源逾時而其他來源成功，下一輪重跑
- **THEN** 保留失敗狀態並只加入尚未存在的資料

#### Scenario: 跨 feed 與統計修訂
- **WHEN** 同一科技新報文章出現在兩個 feed，或同一期報告更新
- **THEN** 不建立重複事件，保留來源與期別

### Requirement: 來源檢查與離線測試

系統 MUST 提供維護者單次擷取及來源健康查詢；測試 MUST 可用離線 fixtures 驗證解析、去重、營收口徑與失敗行為。讀者不得取得測試 fixtures、擷取診斷或維護設定。外部來源失效時 MUST 保留已發布研究與最後有效數值，在數值旁標實際期間及必要缺口，詳細失敗狀態只供管理介面查詢。

#### Scenario: 未取得資料
- **WHEN** 所有外部來源暫時失效
- **THEN** 網站仍顯示地圖與既有內容，讀者可識別資料時點與缺口，維護者可查來源失敗原因

### Requirement: 指標自動更新與重跑隔離

免費公開指標來源 MUST 接入既有每小時更新及防重疊機制；重跑 MUST 依指標、資料集／對象、期別及口徑去重並保留真實修訂。某指標來源失敗 MUST 不阻止其他來源、事件或既有營收觀測成功；既有來源識別及歷史資料 MUST 保留，數值更新不得自動改寫研究判讀。

#### Scenario: 指標解析失敗但新聞成功
- **WHEN** 官方數值格式變動而其他新聞來源可解析
- **THEN** 指標來源顯示失敗與原因，新聞照常保存，舊觀測與查核判讀仍可閱讀

### Requirement: 更新節奏有界且部分失敗隔離

系統 MUST 每小時檢查到期來源，公告預設每小時、營收（供題材代理指標使用）預設每日更新，並支援維護者單次更新。請求 MUST 遵守提供者限流；逾時、429、403 或格式改變時不得阻塞其他來源或刪除有效資料。主機停機後 MUST 可補跑到期任務，不宣稱停機期間持續更新。營收抓取只保存題材代理指標所需的營收，不保存損益、資產負債或每股盈餘。

#### Scenario: SEC 暫時限流
- **WHEN** SEC 回傳 429 而台灣來源可正常讀取
- **THEN** SEC 依限流資訊延後重試，其他來源完成，既有 SEC 營收數值仍可閱讀

#### Scenario: 營收更新仍成為事件
- **WHEN** 台灣月營收來源取得新一期營收
- **THEN** 寫入營收觀測供題材代理指標使用，並照常建立可追溯的營收事件；不另外產生公司財務頁或財務分頁

## REMOVED Requirements

### Requirement: 財務觀測可重現且不跨申報混用

**Reason**: v2 財務儲存與財務匯入隨公司財報功能剃除（2026-10-23 產品決策）。

**Migration**: 營收觀測的去重與修訂保留在既有營收抓取與題材指標規則中（theme-indicators「重跑與官方修訂可追溯」）；v2 財務表以 migration 0017 刪除，刪除前先備份。

### Requirement: 來源能力限制與官方補錄

**Reason**: 官方財務補錄與損益、資產負債、現金流等指標隨公司財報功能剃除。

**Migration**: 維護者不再補錄財務數值，`/api/admin/financial-imports` 與後台「財務補錄」移除；季度損益與資產負債來源從 `sources.yaml` 移除，只保留月營收與 SEC 營收供題材代理指標。
