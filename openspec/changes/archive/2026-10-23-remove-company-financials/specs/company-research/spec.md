# Spec Delta

## ADDED Requirements

### Requirement: 公司比較只並列研究內容

公司比較 MUST 支援 2 至 4 家不同公司，並列各公司的業務模式、供應角色、產品、風險、研究判斷與缺口；選擇少於 2 家、多於 4 家或重複公司 MUST 拒絕並說明原因。比較 MUST 固定於同一個研究版本，不呈現任何公司財務數值、排名或財務口徑選擇。某公司缺少某項研究內容時 MUST 明示缺口，不得以其他公司的內容補齊或推估。

#### Scenario: 比較兩家公司的供應角色
- **WHEN** 讀者選擇台積電與日月光比較
- **THEN** 並列兩家公司的業務模式、供應角色、產品與風險，頁面不出現營收、EPS 等財務數值或財務口徑選單

#### Scenario: 選擇超過上限
- **WHEN** 讀者嘗試加入第 5 家公司
- **THEN** 系統拒絕並說明比較只支援 2 至 4 家不同公司

#### Scenario: 某公司缺少風險段落
- **WHEN** 被比較的公司研究尚未撰寫風險
- **THEN** 該欄明示尚未研究，不留白也不以其他公司內容代替

## MODIFIED Requirements

### Requirement: 固定模板公司頁與唯一識別

系統 MUST 合併同一公司的跨環節角色並提供唯一新版公司研究頁，以穩定公司身分識別、保留 canonical ticker 入口相容。新版 MUST 顯示商業模式、產品線、客戶／供應商、競爭者、業務曝險、風險與來源，不提供公司財務數值或財報頁；既有公司網址 MUST 轉到對應的唯一新版公司研究，legacy API 保持可用但不再回傳財務欄位。未知公司 MUST 回傳不存在，資料不足 MUST 在相關內容旁精簡說明，不填零或生成假內容。

#### Scenario: 跨環節公司
- **WHEN** 使用者從運算或網通開啟博通
- **THEN** 進入同一公司頁，並可看到兩個環節角色與回到環節研究的連結

#### Scenario: 舊 ticker 入口
- **WHEN** 開啟既有公司網址或呼叫既有公司 API
- **THEN** 舊公司網址轉到對應的唯一新版公司研究，既有公司 API 仍可使用，回應不含財務欄位

### Requirement: 深研內容與業務曝險界線

首批五領域的 26 家公司 MUST 完成商業模式、產品用途、差異、已公開客戶／供應商、競爭、風險與來源的研究檢閱。未公開、未取得、未研究及不適用 MUST 可區分；有根據的缺口可保留，但不得以空模板視為完成。公司總營收不得當成特定 AI 產品營收，未公開占比不得自行估計。

#### Scenario: 公司沒有揭露液冷收入
- **WHEN** 公司提供液冷產品，但只揭露合併總營收
- **THEN** 產品能力不以公司總營收代表產品收入，液冷收入占比明示未取得或未公開及其查核依據

## REMOVED Requirements

### Requirement: 基本財務保留定義與修訂

**Reason**: 公司財報功能剃除（2026-10-23 產品決策）：沒有穩定的財務資料 API，累積期數不足以支撐基本財務頁。

**Migration**: 讀者不再取得公司財務數值。題材所需的公司營收改由 theme-indicators 的營收代理觀測提供；v2 財務表以 migration 0017 刪除，刪除前以 `research_lab.py backup` 保存。

### Requirement: 財務圖表與公司比較不得混用口徑

**Reason**: 公司財務圖表隨公司財報功能剃除；公司比較改為只並列研究內容，原條文的財務比較規則已不適用。

**Migration**: 公司比較改由「公司比較只並列研究內容」規範，`/api/v2/compare` 不再接受 `basis`、不回傳 `metrics`；台灣月營收只作為題材代理指標，不再於公司頁呈現歷史。
