# Spec Delta

## MODIFIED Requirements

### Requirement: 可重現啟動與持久化

系統 MUST 提供容器設定、環境變數範例、資料庫遷移與研究初始化；停止／重啟 MUST 保留資料。讀者 API MUST 維持唯讀語意，管理寫入 MUST 使用獨立授權邊界；資料庫、Git 編輯空間與流程管理介面預設只在本機或內部可達。動態服務（資料庫、API、網站、排程與讀者入口）本版供本機及私人網路使用，讀者入口不得轉送管理路徑；對網際網路公開的只有不含伺服器的已發布研究靜態快照。

#### Scenario: 新環境與重啟
- **WHEN** 維護者依 README 啟動並重啟服務
- **THEN** 可開啟產業圖，資料庫保留既有事件，其他專案服務不受影響

#### Scenario: 公開版不開放動態服務
- **WHEN** 維護者部署公開靜態快照
- **THEN** 資料庫、API、網站、排程與讀者入口的連接埠仍只綁本機或私人網路，公開版不需要連到任何一項
