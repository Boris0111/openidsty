# Spec Delta

## Purpose

提供以公司代號識別且可互相跳轉的公司研究頁，彙整產業角色、可追溯企業關係、官方基本財報與相關事件，協助非專業投資人了解公司在供應鏈中的定位與資料限制。

## ADDED Requirements

### Requirement: 固定模板公司頁與唯一識別

系統 MUST 以 canonical ticker 識別公司並合併跨環節角色；公司頁 MUST 顯示公司定位、各環節角色、財報、企業關係與事件。未知公司 MUST 回傳不存在狀態，缺少資料不得填零或生成假內容。

#### Scenario: 跨環節公司
- **WHEN** 使用者從運算或網通開啟博通
- **THEN** 進入同一公司頁，並可看到兩個環節角色

### Requirement: 關係圖方向與分級

公司圖 MUST 呈現中心公司、直接關聯公司及已收錄的鄰居間關係；供應流向、策略合作與單雙向 MUST 可分辨。節點大小 MUST 依 high／medium／low／unknown 業務關聯分級，而非市值、tier 或證據強度。每個公司節點 MUST 可跳轉公司頁。

#### Scenario: 供應與合作並存
- **WHEN** 兩家公司同時存在供應及合作關係
- **THEN** 圖上保留兩種類型並可閱讀各自來源與方向

### Requirement: 候選與已確認關係分離

系統 MUST 預設只顯示已確認關係，並允許使用者開啟待驗證候選。候選 MUST 使用不同線型、狀態及來源資訊，不得因人工核可而改寫原始證據類型。

#### Scenario: 查看待驗證候選
- **WHEN** 使用者開啟候選切換
- **THEN** 額外顯示候選並明確標示需驗證，未知業務關聯程度維持預設大小

### Requirement: 財報期間與來源

基本財報 MUST 支援營收、年增率、毛利率與 EPS；每筆 MUST 記錄來源、發布時間、期間、幣別及單季／累計／年度口徑。衍生指標 MUST 僅使用同口徑資料計算，缺少輸入不得計算。

#### Scenario: 累計財報
- **WHEN** 官方提供半年累計資料
- **THEN** 介面標示累計期間，不得直接標成第二季單季
