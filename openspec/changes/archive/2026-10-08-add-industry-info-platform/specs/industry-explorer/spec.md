# Spec Delta

## Purpose

提供公開的半導體與 AI 伺服器產業鏈導覽，讓使用者從完整環節圖取得環節定位、代表公司與來源資訊，再比較公司或沿事件的可解釋路徑深入研究。

## ADDED Requirements

### Requirement: 完整產業圖與環節導覽

系統 MUST 顯示所選產業的全部環節，保留有向關係與回路；跨產業鄰接環節 MUST 標示為外部環節。點選環節 MUST 顯示定位、公司、題材、監測指標及來源散文。

#### Scenario: 開啟並選擇環節
- **WHEN** 使用者開啟產業圖並點選散熱
- **THEN** 可讀取散熱定位與代表公司，並跳轉公司頁
- **AND** 可縮放、平移及重設圖形，亦可從文字清單選取環節

### Requirement: 公司並排比較

系統 MUST 支援選取二至四家公司比較角色、所屬環節、基本財報與近期事件。財報 MUST 顯示期間及幣別；不同口徑不得偽裝為同一期比較。

#### Scenario: 比較缺少財報的公司
- **WHEN** 比較的其中一家公司尚無財報資料
- **THEN** 其欄位顯示尚未取得，其他公司仍可閱讀

### Requirement: 可解釋且可終止的事件影響路徑

系統 MUST 提供上下游、題材橫向及共同下游手足三種遍歷，記錄已訪問節點並保留路徑種類；結構推導 MUST 標示為 inference，不得宣稱相關公司必然受惠。

#### Scenario: 液冷事件與圖中回路
- **WHEN** 由散熱事件查詢影響範圍
- **THEN** 可透過題材找到電源、透過共同下游找到 PCB
- **AND** 遇到資料中心與運算的回路仍可終止
