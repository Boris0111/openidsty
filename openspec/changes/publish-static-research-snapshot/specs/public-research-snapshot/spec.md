# Spec Delta

## Purpose

讓讀者在網際網路上閱讀已發布研究的產業結構，而不必連到私人研究服務：維護者把一個已發布研究版本匯出成不含伺服器的靜態快照，部署到免費 CDN，私人服務停機時公開版仍可閱讀。

## ADDED Requirements

### Requirement: 公開內容限於已發布研究結構

公開快照 MUST 只包含一個已發布研究版本的研究結構，涵蓋以下內容：
- 環節地圖與環節閱讀。
- 供應鏈。
- 公司、產品、供應角色、術語與研究頁。
- 題材全文與目前判讀。
- 關係圖。
- 搜尋與公司比較。
- 研究引用的文件出處。

快照 MUST NOT 包含以下內容：
- 事件與事件候選。
- 傳聞觀察。
- 題材指標數值。
- 判讀版本歷史。
- 收藏更新。
- 資料覆蓋。
- 來源設定與執行狀態。
- 草稿、管理介面及其 API。

#### Scenario: 題材頁不出現事件與指標
- **WHEN** 讀者在公開版開啟任一題材頁
- **THEN** 可閱讀研究判讀、技術與供應鏈及里程碑，頁面沒有事件清單、指標數值或判讀歷史，也沒有連往事件頁的入口

#### Scenario: 快照檔案不夾帶排除資料
- **WHEN** 維護者檢查一份匯出的快照
- **THEN** 快照內沒有事件、事件候選、來源執行狀態或錯誤訊息，也沒有管理、草稿或覆蓋相關的檔案

### Requirement: 快照對應單一已發布版本且內容一致

一份快照 MUST 只來自一個已發布研究版本。快照內每筆研究回應 MUST 與私人研究服務對該版本的同一請求相同，只移除排除的欄位。草稿與未發布內容 MUST NOT 進入快照。

#### Scenario: 匯出後研究又有新發布
- **WHEN** 維護者匯出版本 A 之後，私人服務又發布了版本 B
- **THEN** 已建置的公開版仍完整呈現版本 A，不混入版本 B 的任何內容

#### Scenario: 指定其他版本的連結
- **WHEN** 讀者開啟帶有其他研究版本識別的公開版連結
- **THEN** 頁面說明此公開版只收錄快照版本，並提供回到快照版本同一頁的入口，不顯示空白或錯誤的內容

### Requirement: 公開版閱讀不依賴私人服務

公開版 MUST 只由靜態檔案組成。閱讀時 MUST NOT 向私人研究服務、資料庫或任何 `/api` 路徑發出請求。私人研究服務停機時，公開版的所有頁面 MUST 照常可讀。

#### Scenario: 私人服務停機
- **WHEN** 私人研究服務全部停止
- **THEN** 公開版的地圖、供應鏈、公司、題材、搜尋與比較仍正常閱讀

### Requirement: 搜尋、目錄篩選與比較和私人服務一致

公開版的搜尋、目錄篩選與分頁、公司比較 MUST 給出和私人服務對同一版本相同的結果。

- **搜尋**：相同的項目與排序。
- **目錄篩選**：相同的成員與順序。
- **公司比較**：相同的欄位內容與公司順序。

輸入檢查 MUST 與私人服務一致，例如比較須選 2 至 4 家不同公司、搜尋字詞不得為空。

#### Scenario: 以別名搜尋公司
- **WHEN** 讀者在公開版以公司的中文別名或上市代號搜尋
- **THEN** 結果的項目與順序和私人服務對同一版本的搜尋相同

#### Scenario: 組合篩選公司目錄
- **WHEN** 讀者同時選擇上市市場、供應角色與應用範圍篩選公司目錄並翻頁
- **THEN** 每一頁列出的公司與順序和私人服務相同，最後一頁之後不再提供下一頁

#### Scenario: 比較任意公司組合
- **WHEN** 讀者在公開版選擇任意 2 至 4 家公司比較
- **THEN** 每家公司的業務模式、供應角色、產品、風險與缺口和私人服務的比較結果相同

### Requirement: 快照未收錄的內容明示而非空白

讀者請求快照未收錄的資料時，公開版 MUST 顯示「公開版未收錄」的說明，並提供可繼續閱讀的入口，例如：
- 不存在的研究 ID。
- 已排除的資料類型。

公開版 MUST NOT 把未收錄顯示成「沒有資料」或空清單。

#### Scenario: 開啟不存在的研究
- **WHEN** 讀者開啟快照中沒有的研究 ID
- **THEN** 頁面說明此研究不在公開版內，並提供回到目錄或地圖的連結

### Requirement: 公開版標示版本、證據程度與免責

公開版每一頁 MUST 顯示以下內容：
- 快照的研究版本發布日期。
- 「內容不構成投資建議」的聲明。
- 結構推導屬於有條件推論的說明。

研究主張 MUST 沿用一般閱讀的三級證據程度：有明確證據支持、有條件推論、仍待核實。

#### Scenario: 讀者開啟任一頁
- **WHEN** 讀者開啟公開版的任一頁
- **THEN** 頁尾顯示快照研究版本的發布日期與不構成投資建議的聲明

### Requirement: 建置驗證快照完整且無排除資料

建置公開版時 MUST 自動驗證以下事項：
- 每個公開頁面都能完整載入，所需的快照資料沒有缺漏。
- 閱讀過程沒有 `/api` 請求。
- 快照不含排除的資料。

任一項失敗，建置 MUST 失敗，不得產出可部署的輸出。這些驗證 MUST 納入自動檢查，以 fixture 快照執行，不需要私人服務。

#### Scenario: 快照缺漏一筆研究
- **WHEN** 快照缺少某個公開頁面需要的研究資料
- **THEN** 建置驗證失敗並指出缺漏的頁面與資料，不產生可部署的輸出

### Requirement: 部署由維護者執行且可回復

公開版 MUST 由維護者在研究發布後手動建置與部署，研究發布 MUST NOT 自動觸發公開部署。部署輸出必須符合下列條件：
- MUST NOT 含有祕密、管理憑證或私人服務的位址。
- MUST 附帶安全標頭，並依內容性質設定快取規則。

回復 MUST 能透過重新部署前一份已保存的快照完成。

#### Scenario: 回復上一份公開版
- **WHEN** 新部署的公開版有問題
- **THEN** 維護者依文件重新部署前一份保存的快照輸出，公開版回到前一個研究版本，私人服務不受影響
