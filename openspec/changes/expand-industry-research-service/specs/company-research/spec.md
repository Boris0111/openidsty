# Spec Delta

## MODIFIED Requirements

### Requirement: 固定模板公司頁與唯一識別

系統 MUST 合併同一公司的跨環節角色並提供唯一新版公司研究頁，以穩定公司身分識別、保留 canonical ticker 入口相容。新版 MUST 顯示商業模式、產品線、客戶／供應商、競爭者、業務曝險、風險、基本財務與來源；legacy 輕量頁及 API 保持可用。未知公司 MUST 回傳不存在，資料不足 MUST 在相關內容旁精簡說明，不填零或生成假內容。

#### Scenario: 跨環節公司
- **WHEN** 使用者從運算或網通開啟博通
- **THEN** 進入同一公司頁，並可看到兩個環節角色與回到環節研究的連結

#### Scenario: 舊 ticker 入口
- **WHEN** 開啟既有公司網址或呼叫既有公司 API
- **THEN** 舊契約仍可使用，新版導覽可解析到對應的唯一公司研究

## ADDED Requirements

### Requirement: 深研內容與業務曝險界線

首批五領域的 26 家公司 MUST 完成商業模式、產品用途、差異、已公開客戶／供應商、競爭、風險與來源的研究檢閱。未公開、未取得、未研究及不適用 MUST 可區分；有根據的缺口可保留，但不得以空模板視為完成。公司總營收不得當成特定 AI 產品營收，未公開占比不得自行估計。

#### Scenario: 公司沒有揭露液冷收入
- **WHEN** 公司提供液冷產品，但只揭露合併總營收
- **THEN** 產品能力與公司整體財務分開呈現，液冷收入占比明示未取得或未公開及其查核依據

### Requirement: 基本財務保留定義與修訂

財務 MUST 支援營收、營收成長、毛利率、營業利益、淨利、EPS、營業現金流、資本支出、現金及約當現金、負債總額；每筆觀測 MUST 保留精確數值、單位、幣別、原始期間、單季／累計／全年／期末口徑、申報主體、來源與修訂。基本及稀釋 EPS 必須可區分，缺值不得填零。

#### Scenario: 財報重編
- **WHEN** 官方修正同一期間的營收
- **THEN** 預設顯示最新有效申報，仍可追溯先前數值、修訂與來源，重跑不新增相同修訂

### Requirement: 財務圖表與公司比較不得混用口徑

公司財務 MUST 可檢閱季度、年度及台灣月營收歷史與來源；比較 MUST 支援 2 至 4 家公司的角色、產品、風險及可比較財務。不同期間、幣別、合併範圍或 EPS 種類 MUST 不混為同一排名或趨勢；不可比較時說明原因。單季衍生值 MUST 保存公式及原始觀測，EPS 不得由累計相減假造。

#### Scenario: 台美公司比較
- **WHEN** 同時比較以 TWD 與 USD 申報且財年不同的公司
- **THEN** 原幣金額與實際期間分開呈現，可比較比率明示共同基準，不自動換匯或把不同季度當同季

#### Scenario: 現金流只有累計值
- **WHEN** 尚未取得口徑一致的前一期累計值
- **THEN** 顯示原累計數值，不產生單季現金流
