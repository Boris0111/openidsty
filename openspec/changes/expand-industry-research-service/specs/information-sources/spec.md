# Spec Delta

## ADDED Requirements

### Requirement: 來源能力與事實性質可分辨

來源註冊 MUST 記錄官方申報、官方產品說明、正式技術文件、草案／路線圖或媒體報導等性質，並可宣告指標、適用市場、更新節奏與歷史範圍。來源宣告能力、人工可讀性、實際成功擷取及逐項核對結果 MUST 分開；註冊成功不代表所有數值或公司關係已獲證實。

#### Scenario: 財報與產品說明用途不同
- **WHEN** 官方產品頁證明產品存在，但未揭露收入或客戶
- **THEN** 可引用產品用途，來源能力不被擴張為可取得該產品收入或具名客戶證據

### Requirement: 引用與保存範圍可追溯

引用 MUST 保存文件標題、來源、URL、適用版本／日期、章節或頁碼及實際讀取範圍。引用原文、快照與圖表的保存／展示 MUST 遵循該來源允許範圍；不清楚時只保存連結、定位及自行撰寫的研究。來源失效時仍保留已發布研究與既有合法摘錄，並說明引用限制。

#### Scenario: 參考網站含授權研究圖表
- **WHEN** 維護者參考其他網站的公司研究與圖解服務
- **THEN** 可參考服務概念，但不得將其授權圖表或未核對關係批次當成自有研究發布

#### Scenario: 原始連結失效
- **WHEN** 已發布主張的外部來源連結失效
- **THEN** 主張、查核日期及合法保存的引用仍可讀，連結失效不自動改成新證據或刪除研究
