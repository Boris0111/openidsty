# Spec Delta

## MODIFIED Requirements

### Requirement: 首輪有真實指標樣本

交付 MUST 包含 AAON 所揭露的液冷產品收入與台積電所揭露的 2nm 晶圓營收占比之真實來源解析樣本，以及現有可取得的官方營收代理觀測。營收代理觀測的來源 MUST 限於台灣月營收（TWSE／TPEx）與 SEC 申報營收，只保存營收，不依賴已移除的公司財務儲存；營收來源成功後 MUST 即投影到對應題材指標。所有題材 MUST 顯示各自取得狀態；live 無法取得時 MUST 交付來源限制記錄，離線 fixtures 不得發布到正式 runtime。

#### Scenario: 題材專屬數字與公司整體數字並存
- **WHEN** 查看液冷產品收入、公司整體營收與製程營收占比
- **THEN** 每個數值的衡量對象、單位與證據界線可辨識，不被合併成市場規模或股價判斷

#### Scenario: 月營收更新後投影到題材
- **WHEN** 台灣月營收或 SEC 營收來源成功取得新一期營收
- **THEN** 對應題材的代理指標出現該期觀測並保留來源與期間，即使公司財務頁已不存在
