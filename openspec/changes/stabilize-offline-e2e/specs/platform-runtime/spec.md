# Spec Delta

## ADDED Requirements

### Requirement: 自動檢查不因時序偶發失敗

自動檢查對畫面狀態、版面尺寸或網路請求等非同步結果的判定 MUST 等待結果穩定，或在有界的時間內重試後才判定成功或失敗；同一份程式碼在相同環境重跑時 MUST 得到相同結果。自動檢查 MUST NOT 以整體重跑或自動重試來掩蓋偶發失敗，真正的回歸仍須在第一次執行就失敗。

#### Scenario: 縮放視窗後檢查溢出
- **WHEN** 檢查在改變視窗大小後立即判定頁面有沒有水平溢出
- **THEN** 檢查等待版面穩定後才判定，不因量測時機落在重新繪製之前而失敗

#### Scenario: 隱藏頁面後檢查請求數
- **WHEN** 檢查在頁面隱藏前觸發了請求，接著驗證隱藏期間不再發出請求
- **THEN** 檢查以隱藏前請求全部抵達後的數量作為基準，不把已發出的請求算成隱藏期間的請求

#### Scenario: 真正的溢出回歸
- **WHEN** 某次修改讓頁面在手機寬度持續水平溢出
- **THEN** 檢查在等待時限後失敗，CI 不會因重試而轉為通過
