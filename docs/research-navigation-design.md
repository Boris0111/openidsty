# 完整研究導覽的閱讀設計（task 6.1）

> 部分內容已被 task 10.2、10.3 取代：新舊站改為共用同一個外框，並從產業地圖進入供應鏈。現行導覽見 [讀者導覽](research-navigation.md)；本文件保留 6.1 的設計脈絡。

沿用已接受的液冷走讀、白底藍綠配色、Microsoft JhengHei 字體與研究／來源順序；本輪改善可到達性及返回位置，不重排首條產品內容，也不以放大字體或新標籤取代內容。

## 讀者路徑

1. 既有地圖選環節後可開啟該環節的新版研究；連結保存地圖原來的 layer／segment，回程恢復原選取。
2. `/next` 提供環節、應用、供應角色、產品、公司、題材與術語的完整目錄。應用／角色可繼續展開產品與公司，沒有新研究資料時顯示簡潔界線，不製造完整供應鏈的假象。
3. 公司索引保留全部基本角色，支援市場／角色／分類篩選與分頁；條件存在 URL，切換分類會重設不適用條件，分享及瀏覽器返回保留當時位置。
4. 物件頁提供回目錄、相關應用／角色／產品及返回產業地圖。從舊地圖進來時優先回來時位置；直接開啟分享連結則提供該物件可解析的環節入口。

完整產業總圖由既有入口保留；新版 typed graph 顯示目前研究周邊，明示深度或筆數界線，不能將局部關係圖標成全產業。供應、產品能力、合作、競爭與需求回饋各有圖例及文字說明；選連線讀交付、條件及來源，能力不代表交易。圖形與文字清單均能到同一研究，真正回路保留。

## 畫面與互動

Header 保留品牌與搜尋，增加明確的目錄入口；詳細分類在目錄內以可換行按鈕排列，避免手機 header 被七類導航擠滿。列表使用現有的中文名稱／一句摘要／閱讀連結，依實際研究對象安排篩選；不加入維護數字、來源健康或內部識別碼。

桌機延續目前產品詳情與關係圖；手機依產品、內容、文字關聯、圖形的順序閱讀，操作不需精準點小節點。選取後焦點移到內容，遵守 reduced motion；鍵盤可以完成目錄、搜尋、節點及連線選取。Resize 保留 pan／zoom，重設由讀者明確按鈕觸發。

返回網址只接受本站既有地圖的 layer／segment／relation 選取，丟棄多餘參數。舊公司頁提供進入新版研究的連結，瀏覽器返回保留原公司頁。私人讀者 gateway 保持只讀已發布研究；舊圖入口的安全選取可轉到對應新版環節，不開放整個 legacy API。

## 走查

離線情境驗證各目錄／篩選／分頁、空資料、未知物件、慢回應不覆蓋選取；真實 release 驗證 17 環節、7 題材及現有公司可到達，產品—角色—公司—證據路徑不中斷。桌機與 390px 手機實際檢視、鍵盤走查、URL 分享／返回及 resize 都需完成，另記錄結果。此文件是實作方向，不是完成證明；全批新分類與深研由 task 8 交付。

## 已實作入口與操作

- 研究首頁：`http://127.0.0.1:3014/next`，保留原液冷走讀。
- 完整目錄：`/next?view=segments`；同一分類列可切換 applications／roles／products／companies／themes／concepts。公司依上市市場、供應角色／環節及應用範圍篩選，後兩者也納入已發布的產品供應能力。全鏈新分類尚由 task 8 補齊，目錄不把未研究內容補造為完整資料。
- 既有地圖選取環節：在環節閱讀上方按「閱讀產品與公司研究」。新版連結固定 release 並保留原來 layer／segment／relation；所有後續物件連結沿用此返回位置。
- 既有公司 `/companies/{ticker}`：按「閱讀完整公司研究」解析至穩定身分。瀏覽器返回可回原公司頁；未知／未初始化的新版入口不影響舊頁閱讀。
- 從目錄閱讀：按「回原目錄」恢復該次分類、篩選及分頁；切換分類則清除原篩選。`index` 回程只接受重新組成的研究目錄，不允許任意 redirect。
- 連線選取：圖上的連線與下方「閱讀連線」共用 `edge` URL；分享及返回恢復連線說明。每條連線可繼續閱讀兩端研究，圖例依實際型別呈現。圖形顯示相鄰範圍，截斷明示；鍵盤可使用文字清單、選單及縮放按鈕。
- Resize 保留既有 pan／zoom；「重設圖形」才重新 fit，縮放比例提供可讀回饋。

舊地圖與 legacy API 只在原本的本機網站入口提供。私人 gateway 不因此開放 legacy；收到合法 map 選取時僅重新導向對應的 `/next?focus=segment-...`，丟棄其他 query，不轉送管理或外部目的地。一般根入口仍轉到研究首頁。
