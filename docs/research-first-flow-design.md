# 第一條閱讀流程：AI 機櫃液冷

> 自 2026-10-20 起，液冷首條流程的專屬頁籤與寫死版型已由一致的供應鏈版型取代（task 10.3），12 條供應鏈都用同一套說明方式，見 [讀者導覽](research-navigation.md)。本文件保留為 task 3.4 的設計紀錄。

目標是讓讀者能回答冷板與 CDU 各交付什麼、雙鴻與 Vertiv 的產品證據支持到哪裡、還缺哪些商業證據。完成這條流程再取得 Boris 的桌機／手機回饋；不先展開 26 家完整深研。

視覺以兩個冷卻回路的原創圖解為重心：白色 #FFFFFF、淺灰 #F3F6F7、文字 #16343A、結構 #203D46、冷卻液 #267A97、帶熱回流 #C14C38。藍／紅表達流向與熱狀態，沒有投資漲跌含義。沿用既有繁體中文系統字體，不增加下載字型；內文 16px、行高 1.8，標題 26px。框線表示元件或責任邊界，不加裝飾性統計卡。

桌機左側維持系統脈絡與產品選擇，右側閱讀選中物件的交付、條件與來源；手機先給直式示意，再給同一閱讀內容，來源就在支持的主張旁。文字靠左，欄寬不超過 80 字元。URL 保存 focus 與 release，返回與分享保留同版內容。搜尋與清單提供圖形之外的完整操作。

```text
桌機：研究標題與問題
      系統圖解／產品選擇 │ 選中產品或公司
      能供應此產品的公司 │ 邊界、條件、來源

手機：研究問題 → 直式圖解 → 產品選擇 → 交付與條件 → 公司 → 證據
```

設計自查：示意圖的資訊是液體回路與設備責任，與正式公司供應圖分開；不把功能相接畫成雙鴻向 Vertiv 供貨。從實際廠商原文整理條件，避開客戶、出貨、容量與收入的無據延伸。沒有來源維護、parser、待核對佇列、raw JSON 或通用進階資訊。對未知之處只解釋會影響當前判斷的限制。

首條流程將保留雙鴻 2025 展會新聞的原發布時間；其中研發措辭不當成已量產。Vertiv 產品頁的 L2L／L2A 分開；額定能力需特定測試條件，首條流程不拿跨型號數字排名。產品能力與公司總營收分開，完整深研尚待後續 task 8.2。
