# 財務、比較與觀察閱讀（task 6.3）

## 閱讀設計

延用白底、`#16343a` 正文、`#18647e` 連結、`#267a97` 圖線、`#cbd8dc` 分隔與 `#526575` 次要文字，Microsoft JhengHei 與既有字級。財務位於公司研究下方，以期間與來源組成可查證的表格／趨勢，不增加營運數字卡片或重排已接受的產品走讀。

```text
公司研究 → 基本財務 → 指標／口徑 → 同口徑趨勢＋原期間表格 → 選一筆查來源與修訂
公司比較 → 選 2–4 家 → 業務／角色／產品／風險 → 各指標原值＋可比較原因
傳聞觀察 → 來源／發布時間／主體與提及 → 原始來源；不繪入正式供應圖
```

財務依來源族、basis、scope、currency、股別及 unit 分開；季、累計、年度、月及期末均能選擇。只有期間不重疊、同口徑的數值才連線，數值仍以精確字串呈現，圖形座標只作視覺定位。來源未提供完整歷史即明示，不把空白補零。

趨勢另要求前後期間連續，缺期不連線；累計、期末與股別未核對的 EPS 只顯示點與原值。圖上有數值尺度，精確原值由表格的可存取名稱與提示保留。手機表格保留期間／值／來源三欄並允許長值換行，不需要左右拖曳。來源展開後移入焦點，關閉時回到觸發位置。

來源及修訂按需讀取，顯示申報日／提供者日期、文件定位、原值／倍率與衍生輸入，保留最新有效值與晚到舊申報的差異。比較遵守 API 回傳的可比性，原幣、原期間及 EPS 股別不換算，不自行拼接報表。傳聞有獨立入口與未證實說明，未知發布日不改用收錄時間。

Companyfacts 的 XML context 擷取方法留在底層 provenance／維護文件，不混入一般財務比較；呈現層僅移除該固定方法說明，其他範圍、精度及申報日限制不刪改。

真實驗收採已註冊來源的單次更新；不開常駐排程、不把 fixtures 寫入 application。公司研究的財年與主要申報來源尚未核對時保留限制，不為顯示曲線猜設定。
