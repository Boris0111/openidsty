# 此裝置關注

在題材列表或詳情按「加入此裝置關注」，首次以按鈕旁已顯示的版本／指標／候選摘要建立基準。主導覽「此裝置關注」集中顯示三種獨立變化：判讀版本、指標新期或修訂、候選資訊。來源取得失敗另列警示，不算未讀；發布日未知只標新收錄／待確認，不稱新發生。

清單與已讀基準保存在 `industryflow.theme-watchlist.v1` 的 localStorage，最多 20 個題材。沒有帳號、跨裝置同步或通知。重新整理仍保留同一瀏覽器的有效清單；儲存損壞／被拒絕時提示並改用本次記憶體，其他閱讀仍可用。部分損壞保留有效項目；不存在或退場題材逐項提示，可移除。

「重新檢查更新」只做公開 GET。「將目前顯示標為已讀」只記錄此回應顯示的三種標記；若來源隨後變更，下一次重新檢查仍會提示，不提前讀取較新內容。移除關注一併移除基準，再加入以新顯示內容重新建立。

更新連結各自指向版本差異、指標修訂明細、待納入判讀資訊；版本連結帶原已讀 version_id。API 不接受個人名單寫入，也不保存已讀狀態。GET `/api/theme-updates?ids=id1,id2` 去重後最多 20 項，不存在／inactive 題材不阻止其他項目。token 排除 HTTP、fetched 等操作時間；觀測內容／revision、候選內容或版本才會改變相應提示。

離線 Playwright 驗證：基準、三類變化、伺服器已變更但舊回應標已讀、重新整理、移除再加入、未知日期、來源失敗、部分損壞、讀寫儲存被拒絕、手機鍵盤。fixtures 僅 browser interception，不進正式資料。
