# 2026-10-16 閱讀 review 與修正

本紀錄只描述使用者檢視預覽後的修正，比對 b613d53 原版、第一輪 3013 預覽及修正後 3013。前輪 backend、技術研究、監測及效能成果保留；本輪沒有改研究原檔、判讀結論或 DB 資料。

## Review 發現

- 環節頁將整組技術欄位及文件列表插在定義與供需之間，推遲了供應角色、傳導與公司內容。技術摘要再接原正文，重複且過長。
- 題材頁堆疊判讀、指標、商業化核對、技術研究、文件監測與全文，里程碑出現兩份。外觀及標籤變動沒有解決內容優先序。
- 「進階資訊」只是內部 ID／狀態／診斷；「技術文件與待核對」呈現維護工作，沒有直接解釋論述。
- 正文仍露出 `odm.upstream`、`beneficiaries`、題材識別碼及 Markdown 路徑。手機直接開啟環節時，較晚出現的產業圖會在捲動後把正文往下推。

## 已執行方向

| 區域 | 修正後 |
|---|---|
| 環節 | 先讀原定義；預設「產業角色」提供供需、傳導、代表公司。「技術與限制」讀原理與導入條件；「追蹤重點」集中指標、風險、題材及事件。 |
| 題材 | 預設「研究判讀」讀結論、正反證據、條件與下一確認點。「技術與供應鏈」讀完整原文及技術限制；「數據與追蹤」讀指標、里程碑實際進展及事件。預期與核對合併為一份。 |
| 揭露 | 移除通用進階資訊、原始診斷、來源設定、事件原始 JSON，以及研究／覆蓋頁的文件監測清單。 |
| 引用 | 論述旁開啟來源後才取得指定版本、章節與摘錄，直接連官方原文。失效引用留缺口，不換最新版；舊分享 URL 仍可閱讀摘錄。 |
| 正文及數值 | 維護欄位轉為供應角色與題材說明，移除行內代碼底色。網址、原文引文、程式區塊保留。金額、幣別、期間與不可比較原因保留；修訂表直接列精確值。 |
| 操作 | 分頁支援左右鍵／Home／End、hash 分享及既有深連結。手機等圖形版面就緒才定位正文，分頁切換不重建圖。 |

本輪沿用原版字體與配色。完整內容分頁後，需要切換才能閱讀另一項任務；每份原研究及來源仍可到達。自動測試能確認操作與資料保留，不能替使用者決定易讀性是否滿意。
