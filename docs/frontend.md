# 前端操作與開發

核心流程：選產業 → 理解環節 → 查看題材與近期事件 → 追溯來源。桌機為產業圖與研究側欄，先讀定義與供應角色，再依技術與限制／追蹤重點切換任務；原 Markdown 散文及來源連結保留在相應分頁。

圖預設保留所選產業的全部節點，依粗略 position 分組；「展開跨產業」加入相鄰跨產業環節。箭頭表示關係方向，供應及需求回饋以線型區分，真實回路保留。選取節點與相鄰關係高亮，其餘淡化；長標籤換行。一般 resize 保留 pan／zoom，另有放大、縮小與「重設視角」。URL 如 `/?layer=ai-server&segment=thermal` 可返回與分享。

手機先提供可讀環節清單及選中環節的局部關係圖。點選立即移至研究面板；「全螢幕完整圖」可查看全部節點，文字清單與關閉按鈕可鍵盤操作。所有圖形選取亦可由文字清單完成。頂部整合搜尋可找環節、題材、公司與 aliases，方向鍵移動結果、Enter 導航、Escape 關閉。

「題材研究」提供七個獨立頁面。狀態保留原查核日期，完整研究依據與相關環節可互相導航；預期里程碑與已發布事件分開，時間經過不自動變更狀態。

題材詳情先顯示目前判讀、支持／反向證據、成立條件、缺口與下一個確認點。每個論點的「查看證據」可用鍵盤展開來源、期間、發布日及原文短摘錄；缺反證如實說明。傳導假設另列機制及條件，全部標 inference。全文與原查核基準仍在同頁，判讀 API 失敗不阻止讀原研究。

題材列表與環節連結附判讀摘要及查核日；事件的「直接相關題材的判讀」連到 `#assessment`。完整結構候選預設收合，可展開所有路徑及公司，不以取前幾筆表示最重要。來源取得限制另展開，與判讀支持程度分開。查核後的候選消息與發布日未知資訊另列，不自動更新研究結論或日期。

「近期事件」支援產業、環節、題材、發布起迄日、內容關聯及例行財報篩選，條件保存在 URL。只有日精度的日期不顯示午夜時間；發布日未知時另標出表／活動日。詳情有有限來源摘錄、分類依據與 inference 路徑，可閱讀原文。

公司 URL 沿用輕量頁，提供名稱、ticker、跨環節定位與相關事件；沒有資訊時顯示單一精簡提示。公司主體與內容提及分開。財報、企業圖與比較展示入口已移除（公司財報資料已於 2026-10-23 由 `0017` 刪除，企業圖 DB 與 API 保留），舊 `/compare?tickers=NVDA,AMD` 導回產業探索並顯示調整說明。

「資料覆蓋」逐項列直接事件、背景統計、未知發布日及可用來源。展開明細可查看真實樣本與歷史限制，下載近 90 日 Markdown 矩陣。「來源狀態」分開呈現註冊、網頁可讀性與 runtime 健康；失敗保留既有研究與事件。

近 30 日沒有直接事件會明示近期缺口，即使近 90 日仍有資料或來源最近成功。待設定／取得失敗來源另列，不把零事件解釋為產業沒有變化。公司提及與結構推導不能補進直接事件。來源排查與單來源重試見 [來源文件](sources.md)，ODM 核對與尚缺摘錄的案例見 [分類核對](odm-classification-audit.md)。

API 切換時立即清空上一份資料，顯示載入狀態，取消舊 request 並檢查 request key；較慢回應不覆蓋新選取。錯誤可「重新取得」，空資料提供覆蓋入口。

Node.js 24，在 frontend 執行 `npm ci`、`npm run dev`，proxy 預設 http://127.0.0.1:8010。production container 使用 `API_ORIGIN=http://api:8000`，變數不暴露於 browser。`npm run typecheck`、`npm run build`、`npm run test:e2e` 驗證型別、建置與實際導航；E2E 預設連 http://localhost:3010。

`npm run test:e2e:offline` 使用本次 production build 的 3011 伺服器與 browser-only API 回應，不需要 Docker／live API；先執行 build。此 suite 與 live E2E 分開，CI 只用離線 suite。fixture 不會匯入正式 app 或資料庫。

離線 E2E 的斷言要等到結果穩定：畫面用 `expect(locator)`，請求數或計算值用 `expect.poll`，不要在 resize、導覽或快轉時鐘之後立刻寫單次的 `expect(await …)`。溢出檢查一律呼叫 `tests/offline/layout.ts` 的 `expectNoHorizontalOverflow`。導覽之後要先等新內容出現，再進行下一步操作。CI 刻意不設 Playwright retries：重試會把偶發失敗和真正的回歸一起蓋掉，偶發失敗要在測試裡修。

配色：紙白 #F7F8FA、深墨 #182C3A、互動藍 #2563EB、題材青 #0D9488、線條灰 #CBD5E1；正文 16px、主標題 28–32px、主要圖標籤至少 14px。系統繁中字體不依賴外部 font CDN。圖形提供結構，閱讀內容提供研究依據。

題材頁的「數據與追蹤」提供指標與商業化核對。至少兩筆同口徑觀測才連線；單笔顯示原期別，修訂與來源可展開。direct 僅為具名產品；proxy 是公司總營收。核對與預期時間分開，來源失敗或數值上升不改題材狀態。

題材頁的版本區以兩個選取器比較欄位；顯示目前序號、原查核日、記錄時間與作者原因，證據 URL 可點回來源。首次基準沒有更早歷史；返回目前判讀入口保留。

此裝置關注、儲存限制與已讀行為見 [theme-watchlist](theme-watchlist.md)。

## 中文閱讀與原值

`lib/display.ts` 統一顯示「有明確證據支持／有條件推論／仍待核實」，題材狀態及來源狀態也由同一模組對照。導覽、breadcrumb、分類及傳導路徑使用 API 名稱；未提供名稱或狀態對照時顯示「名稱待補／狀態待確認」，內部原識別碼不在一般畫面揭露，維護時查 API 或服務紀錄。公司 ticker 與正式技術名稱保留。

研究 Markdown 只轉換文字節點的支持程度與已知名稱，原網址、程式區塊及原文引文保留；不以字串取代修改證據 URL。版本差異的主要欄位、支持程度與狀態使用中文；內部定位碼不另列展開區，原文摘錄及年份保持原值。

金額依原幣顯示萬／億，百分比與百分點分開；零、負值與尚未取得各自顯示。原值保留在數值的 title／無障礙名稱，期別修訂表直接顯示精確數字、單位、幣別與 scope，不在每個數字下增加展開列。格式化不參與 backend Decimal 比較，也不換幣；公司整體收入依舊標成代理指標。

局部 API 失敗顯示中文提示與「重新取得」；不展示原始錯誤、來源設定或通用「進階資訊」。主要閱讀保留可理解的來源受限說明、最後成功與既有研究。狀態頁的「重新查看狀態」只重新取得 runtime 診斷；要重跑實際來源，使用 [來源維護指令](sources.md)，網站沒有公開寫入入口。

## 連線閱讀

實線表示供應角色、虛線表示需求回饋、點線表示舊格式尚未核對；同時有中文圖例。點選線或展開「關係文字清單」可閱讀同一份供應項目／需求機制、介面、條件及證據缺口。

URL 使用既有 layer／segment 加上 `relation=source:target`，例如 `/?layer=ai-server&segment=compute&relation=datacenter%3Acompute`。分享、返回與清除均保留原環節狀態；無效連線提供清除操作。原環節連結不變，切換環節保留當前連線選取；切換產業重新開始。

關係清單的按鈕可用 Tab／Enter 操作；開啟後焦點在詳情標題，關閉後返回原按鈕。手機也可使用同一清單，完整圖的線同樣可開啟說明。連線選取只改 Cytoscape 樣式，不因選取重建圖；一般 resize 保留 pan／zoom，「重設視角」才重新 fit。


共用讀取由 useApi／request-cache 實作，key 包含完整 pathname 與排序 query。同時掛載的相同請求只 fetch 一次；最後一位訂閱者離開才取消，generation 與 hook key 防止舊回應回填。已完成、無訂閱資源 LRU 上限 100。成功結果的 TTL 從取得時計算：industries／segments／themes／graph／研究詳情／特定保存版本 60 秒，coverage／技術文件列表 30 秒；assessment 動態候選、indicators、sources、theme-updates、文件 detail 診斷只合併同時請求。錯誤不保存，重試強制取得並讓現有訂閱者共用新結果。backend 與 Next proxy 均 no-store，不疊第二層 TTL。已讀仍使用畫面顯示的 token 快照。

判讀歷史預設關閉，展開才取得每頁 20 筆版本。選定兩個不同版本才取得 diff；單版不自我比較。分享的 from_version／to_version 自動展開並取得指定保存版本，保留分頁及來源連結。指標修訂顯示已載入／總數，提供載入更多。文件引用在論述來源展開後按需取得指定版本、章節、必要摘錄與引用範圍；不展示監測列表、候選或觀測歷史。引用失效明示缺口，不自動改用最新版。舊引用 URL 保留可讀摘錄頁。文件監測、診斷及核對流程見 technical-document-operations.md。

事件卡片以 source_name 顯示來源，source_id 與未知原始類型不另行揭露，名稱或類型未知時明示待補。版本差異中的必要原文摘錄不替換環節詞彙，年份保留原值，不按金額加入尺度。對應事件名稱、分享比較、原文與年份的回歸案例已納入離線 suite。


## 按研究任務閱讀（2026-10-16 修正）

這輪預覽 review 與前後差異見 [閱讀修正紀錄](reading-review-20261016.md)。沿用原版字體與配色，改動內容優先序與導覽：

- 環節先顯示定義，預設「產業角色」可讀供需、傳導鏈、代表公司；「技術與限制」提供原理、導入條件、瓶頸與替代限制；「追蹤重點」提供指標、風險、題材與事件。
- 題材預設「研究判讀」顯示正反證據、成立條件、缺口與下一確認點；「技術與供應鏈」讀原文及技術研究；「數據與追蹤」讀數值、合併後的里程碑計畫／實際進展及事件。
- Tab 進入分頁後，可用左右鍵／Home／End 切換；每個分頁有對應 hash。既有 #assessment／#versions／#indicators 分享連結自動開啟所屬分頁；舊 #candidates 連結開啟「數據與追蹤」，以一句話說明待納入判讀的資訊已移至維護端，下方照常閱讀公開事件與指標，不再顯示候選清單、候選數或發布日待確認清單（task 6.5，見 [研究覆蓋](research-coverage.md)）。分頁切換不重建產業圖，不改已讀快照。
- 環節、題材、資料覆蓋均不載入「技術文件與待核對」列表；coverage API／下載報告保留維護用技術資料。網站只在具體論述旁提供來源定位及必要範圍。
